## What Was Fixed / Added

### Architecture

- **T1 — Streaming Host Iterator** (`ExpandTargetsStream`): the full
  target list never lives in memory. The dedup map still grows with
  the number of unique IPs (unavoidable), but the slice does not.
  For pure-CIDR inputs `Estimated()` is exact; for hosts files /
  comma lists it is -1 (unknown). `ExpandTargets` is now a thin wrapper
  that collects the iterator into a slice — same external API,
  single source of truth for expansion + dedup + cap.
- **T2 — Mode-dispatch unification** (`wantIdentify` /
  `wantCredential`): a single source of truth for which mode runs
  which stage. Credentials are loaded lazily only when
  `wantCredential(mode)` is true, so `ModeScan` (discovery only)
  no longer spends I/O opening user/pass files or holds a cred
  slice in memory.
- **T3 — Proxy unification** (`credential.DialTCP`): every TCP-only
  authenticator now picks up the global `--proxy` / `--socks5`
  configuration automatically. No per-plugin proxy wiring. The
  five remaining authenticators that built their own `net.Dialer`
  (IMAP, POP3, NFS, rsync, rabbitmq) were migrated; UDP and
  library-native dialers (BACnet, LDAP, SMB) are untouched.

### Output

- **T4 — SARIF 2.1.0 sink** (`--output-sarif`): the SARIF JSON
  document is assembled and emitted at `Close()` time. Credential
  hits are SARIF level `error`; plain service detects are `note`.
  GitHub Code Scanning can ingest the output directly. Eight new
  unit tests cover schema conformance, level mapping, rule ID /
  URI shape, open-and-close round-trip, empty scan, and 50-goroutine
  concurrent writes.

### Protocol coverage

- **T5 — SMTP credential** (`AUTH LOGIN`, RFC 4954): 25 (plaintext),
  465 (implicit TLS), 587 (plaintext — STARTTLS upgrade deferred).
  Hit on SMTP reply `235`.
- **T7 — Tomcat Manager credential** (HTTP Basic on
  /manager/html): 8080 / 8443 / 80 / 443. Hit on 200 or 302;
  miss on 401; 403 / 404 = not a Tomcat manager.
- **T8 — JDWP credential**: 8000 / 5005 / 4000 / 8453. Hit on
  matching the 14-byte ASCII `JDWP-Handshake` magic. Credential-less
  — returns `Method=AuthNone` to honour the Authenticator interface
  contract, same pattern as BACnet / Modbus / NFS.

Authenticator roster grew from 26 to **29**; the registry
regression-test (`TestRegistryHasAllAuthenticators`) was updated
to pin the new names.
